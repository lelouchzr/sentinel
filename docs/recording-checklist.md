# Recording checklist

## Before recording

- [ ] Use the `projet/sentinel` worktree; leave the original project on main.
- [ ] Run `uv sync --locked --python 3.12` and `make check`.
- [ ] Set terminal to 140×42 and a readable dark theme. Test function keys (Fn on some Macs).
- [ ] Use only fictional source data. Keep API key input and secret-manager windows off-camera.
- [ ] Configure Meta in the launching shell; run `sentinel doctor` without printing environment values.
- [ ] Rehearse one explicitly requested live case. Check actual provider status and elapsed time.
- [ ] Reset only `.sentinel-record` generated demo state with the documented command.
- [ ] Keep the focused question ready to paste. Do not paste credentials into the question box.
- [ ] Read the 180-second script; its intervals total 180 seconds.
- [ ] Prepare the honest manual fallback if current API latency is unsuitable.
- [ ] Optional: start `scripts/record_terminal.py`; output goes under ignored `recordings/`.

## Capture evidence of the completed workflow

- [ ] Real imported event/alert counts, not labels presented as computed values.
- [ ] A selected alert becomes a stable case.
- [ ] Real MCP discovery and at least one model-selected search and specific event retrieval.
- [ ] Distinct Investigator, Evidence reviewer and Reporter activity.
- [ ] An event's original record, source filename/position and SHA-256.
- [ ] Explicit session linkage and chronological evidence.
- [ ] Observed facts, hypotheses, open questions and limitations.
- [ ] Logged benign backup context; do not call it independently proven approval.
- [ ] Actual Markdown/JSON export location and a persisted/reopened case.
- [ ] No private chain-of-thought, keys or unrelated project data on screen.

## After recording

- [ ] Stop at exactly 03:00 in the narration timeline or trim only introduction/outro silence.
- [ ] Confirm any latency edits/cuts are labeled; do not imply uninterrupted live progress if edited.
- [ ] Open exported reports and check cited IDs resolve to the case dataset.
- [ ] Verify the capture has readable text and no secret entry.
- [ ] Keep large video/cast files out of Git; retain useful local artifacts under `recordings/`.
