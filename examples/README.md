# Original sample vocabulary

[vocabulary.ko-fr.tsv](vocabulary.ko-fr.tsv) is a small original Korean/French fixture with a header row. It can be used to exercise field mapping, Unicode handling, and a basic request/borrowing scenario.

It contains no personal deck export, textbook scan, or recorded speech. The translations are illustrative and should be reviewed for the chosen teaching context before a public learning-quality claim. Scenario generation and transcription are not precomputed by this fixture.

Keep real user exports, page images, and recordings outside the repository in the ignored private-data directories. Add only original or explicitly authorized, non-personal examples here.
